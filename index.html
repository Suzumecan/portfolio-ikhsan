📁 Cyber Security Project | Telkom DigiUp 2025

🔒 Attack & Defense: IDS Implementation dengan Snort

📌 Title

Attack dan Defense serta membangun Sistem IDS dengan Snort untuk Mendeteksi Serangan pada Jaringan/Server Ubuntu 22

️ Problem

Terdapat sebuah Website HTTP hasil dari server APACHE2 yang saya hosting lokal di Ubuntu Server, dan masih ada banyak kerentanan, salah satunya adalah mudah di-DDOS dan websitenya down.

✅ Solution

Saya melakukan hardening di Ubuntu Server tepatnya di server APACHE2 agar web lokal host yang saya host tidak mudah di-DDOS ataupun ada kerentanan lainnya. Membangun sistem Intrusion Detection System (IDS) menggunakan Snort untuk mendeteksi dan memonitor serangan pada jaringan/server.

🛠️ Tools Used
Nmap SQLMap Wireshark Hydra UFW Firewall Apache Nginx Snort
